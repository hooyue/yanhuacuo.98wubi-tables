# 去识别码重编码报告（v0.2，2026-09-13）

对 `98五笔单字表-【多义】.txt` 执行去识别码重编码。本报告记录规则、重码率前后对比与全部结构变化。

## 裁定规则（用户裁定）

1. **全码去识别码**：2 码元字全码 3 位 → 2 位（1,856 字）；3 码元字全码 4 位 → 3 位（6,150 字）。4 码元字（16,848）、键面字（41）、一级简码 25 行不动。
2. **冲突处理：简码全部让位**——去识别码后的全码落入已有简码行时，该行原简码字（含行首指定简码）全部移出该行；被移出字的全码及其他简码不受影响，不会从码表消失。
3. **字序**：有全码落入或驱逐发生的冲突行按频率重排（字频 = 超集-rime格式码表.txt 权重，无权重字排末）；仅迁出、无冲突的行保留原相对序；未变动行原样不动。
4. **变体字**：双码按码位去末位后合一去重（矢 tdt/tdu→td、尕 bip/biu→bi）；賚窵鋏錏錸鴝鷀为 4 码元双码，均不变化；忸 表内仅 nnh，保持不动。
5. 全表按编码字母序重排，迁空的行删除。
